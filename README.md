# 圣娅快跑 · SEIA RUN

> 蔚蓝档案（Blue Archive）同人 3D 无尽跑酷。博览会限定追逐赛，现在开跑。

Three.js + Vite 实现的三车道无尽跑酷：左右换道、跳跃、滑铲，在千年博览会的街道上甩开身后的追兵，顺便收集青辉石。

![fan game](https://img.shields.io/badge/BLUE%20ARCHIVE-FAN%20GAME-3d7bfd) ![three](https://img.shields.io/badge/three.js-0.180-000) ![vite](https://img.shields.io/badge/vite-6-646cff)

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建到 dist/
npm run preview    # 预览构建产物
npm run package:desktop   # 打包 Electron 桌面版
```

URL 参数：`?char=hina` 指定初始角色，`?play=1` 跳过菜单直接开跑。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 换道 | ← → / A D | 左右滑动 |
| 跳跃 | ↑ / W / 空格 | 上滑 |
| 滑铲 | ↓ / S | 下滑 |
| 暂停 | Esc / P | 右上角按钮 |
| 静音 | M | 暂停菜单 |

主菜单点击学生或追兵可以听语音、看动作。

## 玩法

- 三条车道，撞到障碍不会立刻结束，但会把追兵拉近；追兵贴到身后就结束。
- 追兵距离就是血量：鳄鱼出现在画面里代表你已经被追上了，越近越危险。
- 得分 = 逃逸距离 + 青辉石 × 10，最高分存在 localStorage。

## 角色

圣娅、日奈（常服 / 泳装 / 礼服）、妃咲（常服 / 泳装）、瞬（常服 / 幼女 / 泳装 ×2）、桃井、绿、爱丽丝、Kei。
游戏开发部四人（桃井 / 绿 / 爱丽丝 / Kei）的追兵是早濑优香，其余角色是机器鳄鱼。

## 本次修改

- **追兵常驻可见**：鳄鱼的出现不再依赖「撞到后 2.8 秒」，而是随追兵距离连续缩放/推进，成为世界内的血条。
- **跳跃手感**：重力 -30 → -42、初速 11.2 → 12.6，滞空 0.75s → 0.60s；行距改为按时间间隔兜底（0.86s → 0.74s），满速下落地后仍有时间起跳。
- **滑铲**：连按 ↓ 不再取消滑铲（改为延长），修复「隧道前双击直接撞死」。
- **输入**：跳跃加入 160ms 落地缓冲；滑动判定阈值 18px → 28px，并区分主轴避免斜滑误触。
- **难度曲线**：满速从 1250m 处的 24 m/s 继续爬升到 3000m 处的 28 m/s；每 500m 有里程碑提示。
- **镜头**：撞到时的追兵构图重做；被抓住改为正面机位 + 清理路面道具；竖屏使用独立 FOV 与机位。
- **移动端**：首次开跑弹出滑动操作提示；竖屏开始面板下沉为底部卡片，露出角色；横屏矮屏压缩布局，开始按钮不再被裁掉。
- **信息层**：HUD 增加实时总分；角色列表的换装版本显示「泳装 / 礼服」而不是重复的角色名。
- **音频**：音乐增加追击强度分层（追兵越近鼓点越密）。
- **内容**：新增物资箱、自动贩卖机两种障碍外观（碰撞体不变）。
- **资源**：头像 PNG → WebP（3.0MB → 0.13MB），首屏传输 15.3MB → 12.6MB。
